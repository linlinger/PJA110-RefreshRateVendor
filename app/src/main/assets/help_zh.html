OplusRefreshRate for PJA110 (一加 Ace 2 Pro) — App 版

应用是做什么的

本应用接管面板刷新率调度与 IRIS 独显芯片（PixelWorks）的显示增强，包含三部分：

  • 刷新率调度：智能模式按场景投票决策（游戏 120Hz、静止 3 秒后降档、触摸加速等），也可全局锁定 60/90/120Hz。
  • MEMC 插帧（IRIS 独显）：按应用对芯片下发插帧 / 超分 / SDR2HDR 参数。进出时序对齐 ColorOS（清场 → ABYP → 锁 120Hz → 切 PT → 写参数），息屏或退出时一律兜底回 ABYP 旁路，防止切换风暴导致屏幕冻结。
  • 应用行为自定义：为每个应用单独设置刷新率模式与 MEMC 行为，用户规则优先级最高。

快速上手

  1. 打开「刷新率模式」，选择智能模式或锁定档位。
  2. 要用 MEMC 插帧：先打开「MEMC 插帧」总开关（默认关闭），再在「应用行为自定义」里给目标应用选「强制开启」或在配置文件里加包名。
  3. 验证：adb logcat -s ORR/Iris ORR/IrisExec ORR/PerApp ORR/Service ORR/Scene

iris 命令格式

每条命令对应一次 irisConfig 调用，格式为空格分参：

irisConfig <Type> <Param0> <Param1> ...

JSON 配置里每条字符串就是一条命令（不带 irisConfig 前缀），例如 "258 3 10 0 1"。未填写的参数位置按 0 处理。同一应用的命令按顺序依次下发。

Type 56 — 芯片模式开关（ABP 旁路）

控制独显芯片工作模式，是整个系统安全的核心。本应用自动管理，手动配置时请勿随意下发。

参数值含义
0退出 ABP，芯片进入 PT（Pass-Through）工作模式 —— 插帧/超分生效的前提
1进入 ABP（Analog Bypass）模拟旁路，芯片不处理画面
16待机 ABP（Standby）
32睡眠 ABP（Sleep）—— 系统静止时的默认安全态

读取当前状态用 irisConfig -getfeature 56（注意：-get 56 会段错误，不要用）。sysfs 只读镜像：/sys/kernel/iris/display_mode。

Type 258 — MEMC / HDR 主开关

插帧与 HDR 的总控，视频用 3 参数格式，游戏用 6 参数格式。

位置取值含义
Param 0
模式		 0 / 2 / 10 / 14 / 40 0 = 关闭（禁用 HDR）
2 = 启用 HDR（部分芯片不支持）
10 = 单路 MEMC 插帧（单插，常用）
14 = TNR 时域降噪（部分芯片不支持）
40 = 双路 MEMC 插帧（双插，部分芯片不支持）
Param 1-1忽略位，填 -1 占位。
Param 2
场景（位域）		 见下 按 bit 分段组合（8421 法拼接）：
• bit0~3 场景：0 普通视频 · 2 普通游戏（推荐） · 3 eMV 游戏模式1 · 4 eMV 游戏模式2 · 5 短视频 · 6 允许 eMV API
• bit4~7 延迟档：0 OSD · 1 普通延迟 · 2 低延迟 · 3 超低延迟（延迟越低画面瑕疵越多）
• bit8~11 MEMC 级别：0 级别0
• bit12~15 N2M：0 禁用 · 1 启用
常用组合值：2=OSD 模式 · 18=普通延迟游戏 · 34=低延迟游戏 · 50=超低延迟游戏
Param 3-1忽略位，填 -1 占位。
Param 4
游戏预设		 编号 芯片内部的游戏清单编号（详见 /odm/etc/iris_configs.xml）。255 = 通用默认预设，无独立预设的游戏一律填 255，否则可能因分辨率不匹配不生效。
Param 5
原始帧率		 0 / 30 / 45 / 60 … 游戏的原始帧率。建议填具体数值（如 60），不要填 0 让芯片自动匹配 —— 明确帧率插帧效果更稳。
Param 6
准星辅助		 0 / 1 / 2 0 关闭 · 1 和平精英准星增强 · 2 和平精英全息。其他游戏填 0。

固定格式速记：

游戏（6 参数）: 258 6 10 -1 <延迟档> -1 <预设> <原始帧率>
示例:         258 6 40 -1 34 -1 3 60    (双插 + 低延迟 + 原神预设 + 60帧)
视频（3 参数）: 258 3 10 0 <0=关超分联送 / 1=开>
示例:         258 3 10 0 1

off 段（关闭命令）

iris_config.json 顶层的 "off" 数组是清场命令：每次进入 MEMC 前和退出时都会下发，确保芯片回到干净状态。不可删除，标准内容：

"off": [
    "258 1 0",
    "267 2 3 0",
    "273 1 0"
]

注意事项

IRX 游戏不要开 MEMC！游戏内提供「独显加速 120 帧」选项的游戏（走 IRX 渲染加速）再叠加 MEMC 会双重处理，画面异常且功耗暴涨。
  • 芯片参数因型号而异（X7 PX8768 / X7 Gen 2 PX8778），不确定时以设备 /odm/etc/iris_configs.xml 为准；无独立预设的游戏用 255 通用预设。
  • Param 5（原始帧率）尽量填具体值；很多系统会把游戏锁 40/60 帧再插帧，填游戏实际运行帧率而非目标帧率。
  • MEMC 开启期间本应用会锁定面板 120Hz 并临时接管刷新率决策（优先级 70，用户规则 75 可覆盖），退出后恢复智能调度。
  • 视频类应用（B 站 / 抖音等）用视频格式 258 3 10 0 x；游戏类用 6 参数格式，格式混用可能不生效。

常见问题

现象排查
保存规则提示写入失败正式路径 /data/system/orr/ 需要 privileged 权限；ROM 内置安装可写，debug 安装会自动 fallback 到应用外部目录（功能不受影响）。
打开 MEMC 应用没反应① 总开关没开；② logcat -s ORR/IrisExec 看 irisConfig 是否执行成功；③ 确认 /odm/bin/irisConfig 存在（不存在时 MEMC 自动禁用并在日志说明）。
插帧没效果核对命令格式（游戏 6 参 / 视频 3 参）、预设编号、Param 5 原始帧率；用 irisConfig -getfeature 56 确认芯片是否切到 PT。
某些应用掉到 60Hz确认用智能模式（静止 3 秒才降档是正常行为）；持续掉帧抓 logcat -s ORR/Scene ORR/Service 看投票结果。
屏幕冻结史（本机 known issue）本应用的兜底逻辑保证任何异常路径都回 ABYP。若手动玩 irisConfig 后出问题，执行 irisConfig 56 1 可立即回旁路。
